# 1. Purpose

Icons provide quick visual recognition and reduce cognitive load by supplementing text with meaningful symbols.

The icon system helps:

- Improve navigation
- Enhance usability
- Communicate status
- Reduce visual clutter
- Improve consistency

Icons should complement text rather than replace it.

---

# 2. Objectives

The icon system should:

- Maintain a consistent visual style
- Improve discoverability
- Support accessibility
- Scale across devices
- Remain reusable
- Simplify UI implementation

---

# 3. Design Principles

Icons should be:

- Simple
- Recognizable
- Consistent
- Minimal
- Readable
- Scalable

Every icon should represent a single, well-defined concept.

# 5. Icon Sizes

Representative size tokens:

| Token | Usage                          |
| ----- | ------------------------------ |
| XS    | Dense tables and metadata      |
| SM    | Buttons and inline text        |
| MD    | Navigation and forms           |
| LG    | Cards and feature highlights   |
| XL    | Empty states and illustrations |

All icons should align with the spacing and typography systems.

---

# 6. Semantic Usage

Icons should reinforce meaning.

Representative examples:

| Concept      | Icon Purpose                |
| ------------ | --------------------------- |
| Income       | Positive financial activity |
| Expense      | Spending activity           |
| Budget       | Budget management           |
| Goal         | Savings objective           |
| Report       | Generated reports           |
| Notification | Alerts and updates          |

Icons should always represent the same concept throughout the application.

---

# 7. Navigation Icons

Navigation icons should:

- Be immediately recognizable
- Remain consistent across pages
- Match navigation labels
- Support active and inactive states

Navigation should not rely on icons alone; labels should remain visible where appropriate.

---

# 8. Financial Icons

Financial icons should clearly distinguish different financial concepts.

Representative usage:

- Wallet
- Bank Account
- Card
- Cash
- Investment
- Savings
- Analytics
- Tax (future)

These icons should remain consistent across dashboards, reports, and transactions.

---

# 9. Status Icons

Status indicators should accompany semantic colors.

Representative statuses:

- Success
- Warning
- Error
- Information
- Loading
- Completed
- Pending

Status should never rely solely on color; icons and text should reinforce meaning.

---

# 10. Interactive Behavior

Interactive icons should provide visual feedback.

Representative states include:

- Default
- Hover
- Focus
- Active
- Disabled
- Loading

State changes should remain subtle and consistent.

---

# 11. Accessibility

Icons should support accessibility by:

- Providing descriptive labels where necessary
- Including accessible names for screen readers
- Maintaining sufficient contrast
- Preserving recognizable shapes
- Avoiding icons as the sole communication method

Decorative icons should be hidden from assistive technologies where appropriate.

---

# 12. Usage Guidelines

Recommended usage:

- Pair icons with text for important actions.
- Reuse existing icons before creating new ones.
- Maintain consistent sizing.
- Avoid decorative overuse.
- Use semantic icons consistently.

Icons should improve comprehension rather than add visual complexity.

---

# 13. Best Practices

Recommended practices include:

- Use a single icon family.
- Align icons consistently.
- Maintain uniform stroke and style.
- Reuse established meanings.
- Test recognizability with users.
- Support keyboard accessibility.
- Document new icons before adoption.

Consistency improves learnability and reduces confusion.
