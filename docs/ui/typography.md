# Typography

> This document defines Zentra's typography system. It establishes the font families, type scale, hierarchy, spacing, accessibility guidelines, and usage principles that create a readable, consistent, and professional interface across all supported platforms.

# 1. Purpose

Typography is the primary method of communicating information within the interface.

The typography system aims to:

- Improve readability
- Establish visual hierarchy
- Support accessibility
- Reinforce brand identity
- Ensure consistency
- Reduce cognitive load

Text should remain clear and readable across all devices.

---

# 2. Objectives

The typography system should:

- Define reusable typography tokens
- Maintain consistent hierarchy
- Improve readability
- Support responsive layouts
- Ensure accessibility
- Scale across web and mobile platforms

---

# 3. Typography Principles

Typography should emphasize:

- Clarity
- Consistency
- Readability
- Simplicity
- Proper hierarchy
- Predictable spacing

Every text style should communicate its importance within the interface.

---

# 4. Font Families

Representative font categories include:

## Primary Font

Used for:

- Body text
- Forms
- Navigation
- Tables
- General interface content

---

## Display Font

Used for:

- Page titles
- Marketing pages
- Dashboard headings
- Hero sections

---

## Monospace Font

Used for:

- Financial identifiers
- Code snippets
- Transaction references
- Technical information

Font selections should prioritize readability over decorative appearance.

---

# 5. Type Scale

Representative typography scale:

| Style      | Purpose                         |
| ---------- | ------------------------------- |
| Display    | Landing pages and hero sections |
| H1         | Primary page title              |
| H2         | Major section heading           |
| H3         | Subsection heading              |
| H4         | Card titles                     |
| Body Large | Primary content                 |
| Body       | General reading                 |
| Body Small | Secondary information           |
| Caption    | Supporting details              |
| Label      | Form labels                     |
| Overline   | Categories and metadata         |

A consistent type scale improves visual rhythm throughout the application.

---

# 6. Font Weights

Representative weights include:

- Light
- Regular
- Medium
- Semi-Bold
- Bold

Font weight should reinforce hierarchy without relying solely on size.

---

# 7. Line Heights

Line height should balance readability and efficient use of space.

Guidelines include:

- Larger headings may use tighter spacing.
- Body text should use comfortable spacing.
- Dense tables may use reduced spacing where readability is preserved.

Consistent vertical rhythm improves scanning and comprehension.

---

# 8. Text Hierarchy

Typical hierarchy:

```
Display

↓

H1

↓

H2

↓

H3

↓

Body

↓

Caption

↓

Metadata
```

Higher-level content should receive greater visual emphasis.

---

# 9. Responsive Typography

Typography should adapt across:

- Desktop
- Laptop
- Tablet
- Mobile

Responsive scaling should preserve readability while maintaining the established hierarchy.

---

# 10. Monospace Usage

Monospace fonts should be reserved for structured information such as:

- Transaction IDs
- Reference numbers
- Code samples
- API keys (where displayed)
- Financial identifiers

General application content should use the primary font family.

---

# 11. Accessibility

Typography should support:

- Readable font sizes
- Adequate line spacing
- Sufficient color contrast
- Scalable text
- Clear hierarchy
- Avoidance of excessive capitalization
- Readable paragraph widths

Typography should remain usable without requiring zoom under normal viewing conditions.

---

# 12. Usage Guidelines

Recommended usage:

- Use predefined typography tokens.
- Maintain heading hierarchy.
- Keep paragraph lengths manageable.
- Avoid excessive font variations.
- Use bold text sparingly for emphasis.

Typography should enhance comprehension rather than attract unnecessary attention.

---

# 13. Best Practices

Recommended practices include:

- Reuse standardized text styles.
- Maintain consistent hierarchy.
- Limit font families.
- Avoid decorative typography.
- Test readability across devices.
- Preserve accessibility requirements.
- Review typography regularly.

A restrained typography system creates a cleaner and more professional user experience.

---

# 14. Future Enhancements

Potential improvements include:

- Variable font support
- Adaptive typography
- Dynamic scaling
- Multilingual typography optimization
- Reading mode
- Accessibility-focused font themes
- Automated typography linting
